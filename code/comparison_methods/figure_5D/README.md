# Figure5D illustrative capture schematic

Run from the project root:

```bash
MPLCONFIGDIR=/tmp/fig5d comparison_methods/env/analysis/bin/python sim_paper/code/comparison_methods/figure_5D/plot_hexagonal_capture.py
```

Outputs: data/comparison_methods/figure_5D_hexagonal_capture/ (PNG/PDF/SVG, synthetic positions, provenance).

This user-requested conceptual illustration uses synthetic positions, a common seven-spot hexagonal geometry, and the Figure5A cell-type palette. Dots represent illustrative mRNA locations in the ALBIS panel; larger circles represent contributing cells for scCube/SPIDER. The exact same cell layout is used across panels to isolate representation. It is not a zoom of actual Figure5A data, not a native capture-geometry claim, and not a quantitative performance comparison. scCube's native grid memberships are not circular capture areas.
