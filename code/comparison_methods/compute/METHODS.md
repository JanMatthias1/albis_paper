### Preliminary computational benchmarking

We benchmarked ALBIS, scCube and SPIDER at eight output sizes (10,000–5,000,000 cells), using 556 genes, one computational CPU thread and a single random seed (2025). Methods were executed through their native APIs, preserving their returned representations: explicit molecules for ALBIS, expression and metadata for scCube, and reference-backed expression views for SPIDER. Wall-clock generation time excluded reference construction and VAE training; setup-inclusive time additionally included Splatter reference generation and input loading/preprocessing where applicable. For scCube, a VAE was trained once per size batch and reused in memory, with the measured batch setup cost charged to each size for the setup-inclusive comparison. No model checkpoints were saved. Timing excluded imports/startup, validation, aggregation and output export.

Memory comparisons are preliminary. ALBIS and SPIDER whole-process peak resident memory serves as a proxy for generation memory. scCube generation memory was sampled every 100 ms for 1–5 million cells, retaining the trained VAE and reference in memory; smaller-size generation measurements are unavailable. The setup-memory panel reports method-process peaks, including training and prior within-batch work for scCube, but excludes unmeasured Splatter-process memory. Thus, the memory panels do not constitute fully matched measurements with and without setup. Results represent one observation per method and size, without replicate-based uncertainty estimates.
